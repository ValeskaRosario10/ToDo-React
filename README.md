# 📝 React To-Do List

## 🚀 Features
- Add tasks to a list
- Automatically clear input after adding
- List updates using spread operator
- interactive GUI
-  Easily extendable with delete or complete functionality

## 💡 Key Concepts 
This is a simple React To-Do List app 
- Controlled components
- Immutably updating arrays
- Event handling (`onChange`, `onClick`)
- React `useState` hook
- ES6 spread operator (`...`)
- Dynamic rendering with `.map()`
